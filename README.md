# Expense Tracker

A simple and responsive web application for managing personal income and expenses.

The Expense Tracker allows users to add, edit, delete, and filter transactions while automatically calculating income, expenses, and balance. Transaction data is stored in the browser using Local Storage, so the data remains available after refreshing the page.

## Features

- Add income and expense transactions
- Add transaction amount, category, date, and optional description
- Edit existing transactions
- Delete transactions with confirmation
- Calculate total income
- Calculate total expenses
- Calculate current balance
- Filter transactions by type
- Filter transactions by category
- Store transactions using browser Local Storage
- View monthly income, expenses, and balance
- View category-wise expense breakdown
- Responsive design for desktop and mobile devices
- Form validation with helpful error messages

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
